Luddite Scout

A pre-flight check for a public GitHub repository, before you let an agent or a build near it. Everything runs in your browser.

About and data handling
Optional GitHub token

Without a token GitHub allows 60 API requests an hour from your address, which is enough for roughly ten reviews. A fine-grained token with no permissions raises that limit. It is kept in memory for this page only, never stored, and only sent to api.github.com.

Findings are heuristics. A clean report is not proof a repository is safe.
